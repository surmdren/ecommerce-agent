# ecommerce-agent 🛒

> AI 驱动的电商运营自动化 Agent，专为跨境卖家打造

**定位**：用 AI + Computer Use 自动化执行跨境电商重复运营任务  
**目标市场**：Amazon / Shopify / TikTok Shop 卖家  
**技术核心**：Claude Computer Use API + K8s 沙箱  
**目标**：$5K MRR in 6个月

## 双轨策略

- **轨道1：出海运营 Agent**（优先）— Amazon/Shopify/TikTok Shop
- **轨道2：国内电商 Agent**（后续）— 淘宝/京东/抖音小店

## 核心功能（MVP）

- [ ] Amazon 客服自动回复
- [ ] Listing 标题/描述 AI 优化
- [ ] 多店铺订单状态汇总
- [ ] Review 监控与回复
- [ ] 竞品价格监控
