## 高风险项（必须提前缓解）

### R1：SP-API Solution Provider 审批延迟/拒绝
- **概率：** 中（30%）
- **影响：** 高（整个产品无法上线）
- **触发条件：** 亚马逊审批 SP-API 申请周期 4-8 周，且有拒绝风险
- **缓解措施：**
  1. **立即行动：** 提前准备完整申请材料（Privacy Policy + Terms of Service + 产品说明文档）
  2. **申请策略：** 以"Solution Provider"身份申请，明确说明使用场景（Buyer-Seller Messaging）
  3. **备选方案：** MVP 内测阶段用开发者沙盒测试环境，向内测用户说明正式授权等待中
  4. **时间节点：** Week 1 立即提交，预计 4-8 周审批
- **Owner：** 创始人
- **状态：** ⚠️ 待启动

### R2：AI草稿质量不达预期（采用率 < 50%）
- **概率：** 中（25%）
- **影响：** 高（核心价值主张失效，用户不愿付费）
- **触发条件：** 用户反馈草稿需要大量修改，觉得 AI 没用
- **缓解措施：**
  1. 内测阶段密集收集每次修改记录（修改了什么 → 优化Prompt）
  2. 建立 Prompt 评估体系：每周人工评分 30 条草稿
  3. 分场景优化：优先攻克最常见的"物流查询"和"产品咨询"场景
  4. 最低接受标准：用户只需修改 < 30% 的内容即视为可用
- **Owner：** 创始人
- **状态：** ⚠️ 内测期监控

## 中风险项（建立预案）

### R3：冷启动无法找到内测用户（Week 2 失败）
- **概率：** 中（20%）
- **影响：** 中（延迟产品验证 2-4 周）
- **触发条件：** 微信群招募 1 周后，内测申请 < 3 人
- **缓解措施：**
  1. **降低门槛：** 从"安装测试"降为"帮我看看这个截图，AI会怎么回复？"
  2. **扩大渠道：** 联系闲鱼/淘宝上卖"亚马逊运营服务"的服务商，请他们推荐客户试用
  3. **关系网络：** 通过个人人脉直接找认识的亚马逊卖家
  4. **降价策略：** 内测完全免费，甚至提供 $50 "感谢费"（仅前3名）
- **Owner：** 创始人
- **状态：** ⚠️ 监控中

### R4：付费转化率过低（< 10%）
- **概率：** 中（25%）
- **影响：** 中（Month 1 目标达成困难）
- **触发条件：** 14天试用结束后，付费转化率 < 10%
- **缓解措施：**
  1. 分析流失原因：在试用结束前发"离开调查"问卷
  2. 延长免费试用至 30 天（降低决策压力）
  3. 提供"成功后付费"模式：用 AI 发送的消息，按条收费 $0.2，无月费
  4. 直接电话/微信视频跟进高潜力用户（试用期发送 > 20 条消息的用户）
- **Owner：** 创始人

### R5：小红书内容无流量（算法不推荐）
- **概率：** 中（30%）
- **影响：** 中（Month 3 目标推迟）
- **触发条件：** 发布 5 篇帖子后，每篇平均阅读量 < 200
- **缓解措施：**
  1. 分析爆款内容：研究竞品和相关话题的高赞帖子格式
  2. 调整内容形式：从图文改为视频（小红书视频流量更大）
  3. 启动薯条推广：投入 $30-50 推爆款帖子
  4. 换话题角度：从"AI工具"换为"亚马逊账号健康度""英文客服技巧"等用户更搜索的词
- **Owner：** 创始人

## 低风险项（定期监控）

### R6：竞品出现（新的 AI 亚马逊客服工具）
- **概率：** 中（市场验证后竞品会出现）
- **影响：** 中（价格压力/用户分流）
- **缓解措施：**
  1. 建立品牌护城河（用户案例 + 口碑）
  2. 专注中国卖家本地化（界面全中文、微信支持、国内支付等）
  3. 提高数据壁垒（用户发送记录 → 持续优化AI）
- **监控频率：** 每月

### R7：Claude API 成本超支
- **概率：** 低（有量化的成本模型）
- **影响：** 低（可通过提价或限量解决）
- **成本测算：**
  - Haiku 分类：$0.001/条 × 500条 = $0.50/用户/月
  - Sonnet 生成：$0.010/条 × 500条 = $5.00/用户/月
  - 合计：$5.50/用户/月 vs 套餐价 $49
  - 利润率：88.8%（可控）
- **缓解措施：** 监控每用户 API 成本，若超过 $10/用户则调整 Prompt 长度或切换更便宜模型

### R8：亚马逊平台政策收紧（Messaging API 限制）
- **概率：** 低（但影响大）
- **影响：** 高（需要产品重大调整）
- **缓解措施：**
  1. 定期关注 Amazon Seller Central 政策更新
  2. 所有回复内置合规校验，确保不触发平台违规
  3. 产品架构保持对其他平台（Shopify/TikTok Shop）的扩展可能性

| 场景 | 响应时间 | 应急措施 |
|------|---------|---------|
